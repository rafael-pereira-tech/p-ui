# Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar. From shadcn/ui (new-york-v4), exported as `PUI.Progress`.

## Consumer provides
`value` 0–100.

## Rules
`primary` bar on a `primary/20` track, 8px tall, pill ends. Pair with a text label or percentage; for unknown duration use Spinner.
