# Label

Renders an accessible label associated with controls. From shadcn/ui (base-nova), exported as `PUI.Label`.

## Consumer provides
`htmlFor` = the control's `id`, and the label text.

## Rules
`label` text style (14px medium, leading-none). It dims automatically when its peer control is disabled. Place above fields (gap `space-2`) or right of Checkbox/Switch (gap `space-2`–`space-3`).
