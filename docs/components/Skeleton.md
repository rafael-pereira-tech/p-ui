# Skeleton

Use to show a placeholder while content is loading. From shadcn/ui (new-york-v4), exported as `PereiraUI.Skeleton`.

## Consumer provides
Size and shape via `className` (`h-4 w-[250px]`, `size-12 rounded-full`).

## Rules
`accent` fill with a pulse. Mirror the real layout's shapes and sizes so nothing jumps when data arrives.
