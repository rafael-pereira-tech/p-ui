# RadioGroup

A set of checkable buttons—known as radio buttons—where no more than one of the buttons can be checked at a time. From shadcn/ui (new-york-v4), exported as `PUI.RadioGroup`.

## Parts
`RadioGroup value onValueChange` › `RadioGroupItem value id` + `Label htmlFor`.

## Rules
Use for 2–5 visible, mutually exclusive options; more → Select. Selected dot is `primary` (follows `data-accent`).
