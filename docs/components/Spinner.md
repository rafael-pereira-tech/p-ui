# Spinner

An indicator that can be used to show a loading state. From shadcn/ui (new-york-v4), exported as `PUI.Spinner`.

## Rules
A spinning lucide `Loader2` at 16px in `currentColor`. Put it inside the Button that triggered the work (`<Button disabled><Spinner /> Saving…</Button>`), in an InputGroup addon, or in an Empty/Item for longer loads; prefer Skeleton when the layout is known.
