# Empty

Use the Empty component to display an empty state. From shadcn/ui (base-nova), exported as `PUI.Empty`.

## Parts
`Empty` › `EmptyHeader` (`EmptyMedia variant="icon"`, `EmptyTitle`, `EmptyDescription`) › `EmptyContent` (actions).

## Rules
Say what's missing and offer the next step (one primary Button, one secondary). Centred, dashed `border` optional. Use for no-data tables, empty inboxes, 404s.
