# ButtonGroup

A container that groups related buttons together with consistent styling. From shadcn/ui (new-york-v4), exported as `PereiraUI.ButtonGroup`.

## Parts
`ButtonGroup orientation` › Buttons, `ButtonGroupSeparator`, `ButtonGroupText`; nest ButtonGroups for spaced clusters.

## Rules
Joins borders and corners of adjacent Buttons (usually `outline`). Use for split buttons (action + DropdownMenu chevron), pagers and segmented actions; for a single-choice switcher use ToggleGroup.
