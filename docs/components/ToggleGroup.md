# ToggleGroup

A set of two-state buttons that can be toggled on or off. From shadcn/ui (new-york-v4), exported as `PereiraUI.ToggleGroup`.

## Consumer provides
`type="single"` (segmented control) or `"multiple"`, `value`/`onValueChange`, `ToggleGroupItem value aria-label`, `variant`, `size`, `spacing`.

## Rules
Use as a segmented control for view modes (list/grid) and text alignment.
