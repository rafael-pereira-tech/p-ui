# HoverCard

For sighted users to preview content available behind a link. From shadcn/ui (base-nova), exported as `PUI.HoverCard`.

## Parts
`HoverCard openDelay closeDelay` › `HoverCardTrigger render={…}` › `HoverCardContent`.

## Rules
Preview only (profiles, link previews): never the only way to reach information, since touch and keyboard users may not see it. `popover` surface, w-64.
