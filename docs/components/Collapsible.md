# Collapsible

An interactive component which expands/collapses a panel. From shadcn/ui (base-nova), exported as `PUI.Collapsible`.

## Parts
`Collapsible open onOpenChange` › `CollapsibleTrigger render={…}` › `CollapsibleContent`.

## Rules
Unstyled: bring your own layout. Use for one show/hide region (nested nav groups in the Sidebar); for several stacked sections use Accordion.
